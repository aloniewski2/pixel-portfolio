## User Guide

### 1. Prerequisites
- Install Node.js (version 18 or newer recommended).
- Install MySQL and ensure the `dbclass` database is accessible at `127.0.0.1:3306`.
- Create a `.env` file using your MySQL credentials.

### 2. Setup

### 3. Run the App

Then open http://localhost:3000/customers in your browser.

### 4. Using the App (CRUD)
- Create: Click “Add Customer”, fill in the form, and submit to insert a new row.
- Read: Visit the customers list to view all customers pulled from MySQL.
- Update: Use the “Edit” link beside a customer, adjust fields, and save to update.
- Delete: Click “Delete” for a customer and confirm to remove the record.
